# Практическое задание №2
## Тема: Работа с несколькими классами. Разработка The Sims

### Описание проекта
Простая консольная симуляция жизни персонажа, вдохновлённая игровым процессом The Sims.

### Использованные классы

**House (Дом)**
- Хранит название дома и количество еды.
- Позволяет персонажу готовить еду, спать и отдыхать.
- Взаимодействует с объектом класса `Person`.

**Person (Человек)**
- Хранит имя персонажа, уровень энергии, сытости и настроения.
- Имеет методы для еды, сна, отдыха и изменения потребностей.
- Связан с конкретным объектом класса `House`.

**Simulation (Симуляция)**
- Управляет ходом игрового дня.
- Вызывает действия дома и персонажа.
- Выводит состояние персонажа до и после симуляции.

### Как взаимодействуют классы
Объект `Person` получает ссылку на объект `House`. Благодаря этому персонаж может использовать возможности дома: готовить еду, отдыхать и спать. Класс `Simulation` управляет совместной работой этих объектов.

### Как запустить программу
1. Установить Python 3.
2. Открыть файл `main.py`.
3. Выполнить команду:

```bash
python main.py
```

### Вывод
Создана собственная симуляция из трёх связанных классов. Реализовано взаимодействие персонажа с домом и изменение характеристик персонажа в зависимости от выполненных действий.
